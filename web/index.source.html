tinyprover

tp言語のソースコードを pa言語（記号列）へコンパイルし、Kernel で型検査を行います。pa言語を直接編集して検査することもできます。

tp言語の構文

宣言

構文説明
axiom 名前 : 型;公理（前提）の宣言
def 名前 : 型 := 項;定義の登録
theorem 名前 : 型 := 証明項;定理の証明（def と同等）

型と項

構文説明
Type / Kind宇宙（Type : Kind）
f x y関数適用（左結合）
A -> B関数型（右結合）
forall (x : A), B依存関数型（Π型）
fun (x : A) => bラムダ抽象

pa言語（記号列）の構文

記号操作
*Type をプッシュ
^Kind をプッシュ
$n変数（de Bruijn index、$0 が最内）
#n登録済み定数（0始まり）
>Π型の構築: A B → Pi(A, B)
\λ項の構築: A b → Lam(A, b)
@関数適用: f x → App(f, x)
:前提の登録（スタック: [型]）
!定義・証明の登録（スタック: [型, 項]）

対応例

// tp言語
axiom A : Type;
def id (x : A) : A := x;

// pa言語
*:
#0#0>#0$0\!
