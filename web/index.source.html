pa言語（記号列）の構文

paは左から順に読みます。型や項をスタックに積み、後ろに置いた記号で組み立てます。スタックは、途中の型や項を順番に保持するものです。下の表では右端が最後に積んだ項を表します。

記号操作
*Type をプッシュ
^Kind をプッシュ
$n変数（de Bruijn index、$0 が最内）
#n登録済み定数（0始まり）
>A B を取り出し、引数の型が A、戻り値の型が B の関数型（Π型）を積む。B は引数を参照できる
\A b を取り出し、型 A の引数を受け取って b を返す関数（λ項）を積む
@f x を取り出し、関数 f を引数 x に適用した項を積む
:スタックが [型] のとき、その型を持つ定数を前提として登録し、スタックを空にする
!スタックが [型, 項] のとき、項がその型を持つか検査して定数を登録し、スタックを空にする

恒等関数を書く

*:
#0#0>#0$0\!

*: は、型を表す定数を前提として登録します。最初の定数なので番号は #0 です。続く #0#0> で、その型の値を受け取り、同じ型の値を返す関数型を作ります。

#0$0\ は、受け取った引数をそのまま返す関数です。最後の ! で関数型と関数を照合し、検査が成功すると新しい定数 #1 を登録します。

変数と定数の番号

$0 は最も内側の引数、$1 はその一つ外側の引数です。この番号の付け方をde Bruijn indexと呼びます。たとえば #0#0$1\\ は、型 #0 の引数を二つ受け取り、先に受け取った方を返す関数です。

#0、#1、…は登録順に付く定数番号です。使えるのは、その位置までに登録した定数だけです。

空白と検査

記号の間の空白や改行は省けます。$0 や #12 の記号と数字の間には空白を入れられません。paにはコメント構文がありません。

型検査は : と ! で登録するときに行います。スタックの項が足りない場合、登録時に余分な項がある場合、末尾に未登録の項が残る場合もエラーになります。

tp言語（paの高級言語）の構文

tpでは、paの定数番号や変数番号を名前で書き、型と項を通常の関数の表記で組み立てます。「paを生成して検査」を押すと、名前を番号に変換してpaを生成し、そのpaを検査します。

宣言

構文説明
axiom 名前 : 型;公理（前提）の宣言
def 名前 : 型 := 項;定義の登録
theorem 名前 : 型 := 証明項;定理の証明（def と同等）

型と項

構文説明
Type / KindType は型の型。Type : Kind が成り立つ。Kind 自体には型がない
f x y関数適用（左結合）
A -> B関数型（右結合）
forall (x : A), B依存関数型（Π型）
fun (x : A) => bラムダ抽象

paとの対応

axiom A : Type;
def id (x : A) : A := x;

このソースから、paの例と同じ *:#0#0>#0$0\! が生成されます。A が #0 に、関数の引数 x が $0 に対応します。定数名 id はpaの記号列には含まれません。

宣言に書いた引数は、型では forall、本体では fun に展開されます。上の定義は次のようにも書けます。

def id : A -> A := fun (x : A) => x;

f x y は (f x) y、A -> B -> C は A -> (B -> C) と読みます。forall (x : A), B では、戻り値の型 B に引数 x を使えます。

証明としての型検査

証明例では、Prop を命題の型、Prf P を命題 P の証明の型として宣言しています。theorem 名前 : Prf P := 項; の検査では、その項が Prf P 型を持つことを確かめます。論理規則や自然数の公理も、宣言した前提として使います。

def と theorem は同じ検査を受け、どちらもpaの ! に変換されます。登録後の定数は、型の比較で本体を展開しません。直接書いた (fun (x : A) => x) a は a に簡約されますが、登録済みの id a は展開されません。

「検査成功」は、入力に含まれる前提のもとで項の型が正しいことを表します。前提そのものの正しさや無矛盾性は、この検査では判定しません。
