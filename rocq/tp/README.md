# tp 形式検証

tinyprover の `.tp`（高水準言語）から `.pa`（低水準言語）への解析・変換・出力までを Rocq で実装・証明したコンパイラです。
解析器・変換器を OCaml に抽出し、`pa` 側の共通 codec・型検査器へ接続しています。

## ビルドと実行

```sh
# 検証とテスト
make -C rocq/tp
make -C rocq/tp test

# 抽出した CLI の実行
rocq/tp/_build/tp check examples/basics.tp
rocq/tp/_build/tp compile examples/basics.tp -o /tmp/basics.pa
rocq/tp/_build/tp check-pa /tmp/basics.pa
```

## 証明した保証

高水準な構文から名前解決、`.pa` 出力・再検査までの全経路について、以下を証明しています（追加公理や `Admitted` は使用していません）。

- **構文解析・import 展開の正しさ**: バイト列の字句・構文解析、および import 展開が、独立した仕様と同値であること。
- **名前解決・変換の健全性と完全性**: 名前付き構文から de Bruijn インデックスへの変換が一意であり、宣言順・種類・スコープが保存されること。
- **.pa 出力の往復性と再検査性**: 変換された宣言列を `.pa` バイト列に符号化・復号する往復性（roundtrip）と、生成された `.pa` が独立に再検査できること。

## 信頼境界と制限

- **ホスト環境**: ファイル I/O、実体パスの解決（`realpath`）、依存ファイルの収集は OCaml（ホスト環境）が担当します。
- **名前付き言語の独立理論**: 名前付き言語自体の型理論は独立に定式化せず、核心言語（pa）への宣言的翻訳関係を通じて検証しています。
- **計算資源**: fuel は再帰の深さであり、実機の時間・メモリ内での完了を保証するものではありません。
